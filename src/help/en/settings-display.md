# Display

## Light mode

"Light mode (slow PC)": fewer animations and smaller tiles, so the app runs faster on an old PC.

## Text size

"Text size": Normal (100 %), Large (115 %) or Larger (130 %).

## On-screen keyboard

"On-screen keyboard (touch screen without a keyboard)": an AZERTY and Arabic keyboard for touch tills without a keyboard.

These choices apply to this PC only.
