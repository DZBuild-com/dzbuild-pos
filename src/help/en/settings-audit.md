# Action log

## What is recorded

The action log records sign-ins, sales, voids, discounts, drawer openings, settings changes, backups and updates.

## Checking the log

"Check the log" proves that no line was changed or removed: each line is locked to the one before it, so any change shows.

## A record's history

"History", on a product's record, shows who changed what, with the value before and after.
