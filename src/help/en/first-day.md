# First steps

Follow these steps on the first day. Tick each step you finish: the list stays on this PC.

## Before opening the shop

- [ ] Check the shop's name, NIF and tax regime in [Settings › Shop](route:/settings/shop).
- [ ] Create a user and a PIN for each cashier in [Settings › Users and roles](route:/settings/users).
- [ ] Plug in the receipt printer and print a test page in [Settings › Hardware](route:/settings/hardware).
- [ ] Plug in the scale or the customer display if you have one, on the same screen.
- [ ] Add your products one by one or [import them from Excel](help:products).

## Protect your data

- [ ] Choose a USB stick for the second copy in [Settings › Backups](route:/settings/backups).
- [ ] Write the owner's PIN down somewhere safe: it is asked to restore a backup.
- [ ] Exclude the data folder from the antivirus ([how to](help:antivirus)).

## The first day

- [ ] Open the till with the opening float (the change put in the drawer) on the [Cash register](route:/cash) screen.
- [ ] Make a test sale, then a return, to see the receipt and the return note.
- [ ] Close the till in the evening (Z): a backup is made automatically.

> To practise without touching your real data, open the [demo shop](help:demo).
