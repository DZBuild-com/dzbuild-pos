# Shortcuts

Settings › Shortcuts changes the key of each action of the sale screen.

## Change a key

- "Change" beside the action, then press the new key: an F key (except F11, kept for the scale), Ctrl + a digit, or Esc.
- A key another action already has is refused, naming that action.
- "Save the keys" applies them to every till of the shop.

## Back to the original keys

- "Restore the default keys" puts back F1 to F12, Esc and Ctrl+1 to Ctrl+5 as on the first day.
- The till's F1 help always shows the keys in force.
