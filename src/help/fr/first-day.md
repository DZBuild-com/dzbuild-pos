# Premiers pas

Suivez ces étapes le premier jour. Cochez chaque étape faite : la liste reste sur ce PC.

## Avant d'ouvrir la boutique

- [ ] Vérifiez le nom, le NIF et le régime fiscal de la boutique dans [Réglages › Boutique](route:/settings/shop).
- [ ] Créez un utilisateur et un code PIN pour chaque caissier dans [Réglages › Utilisateurs et rôles](route:/settings/users).
- [ ] Branchez l'imprimante de tickets et imprimez une page de test dans [Réglages › Matériel](route:/settings/hardware).
- [ ] Branchez la balance ou l'afficheur client si vous en avez un, dans le même écran.
- [ ] Ajoutez vos produits un par un ou [importez-les depuis Excel](help:products).

## Protéger vos données

- [ ] Choisissez une clé USB pour la copie de secours dans [Réglages › Sauvegardes](route:/settings/backups).
- [ ] Notez le code PIN du propriétaire dans un endroit sûr : il est demandé pour restaurer une sauvegarde.
- [ ] Excluez le dossier des données de l'antivirus ([comment faire](help:antivirus)).

## La première journée

- [ ] Ouvrez la caisse avec le fond de caisse (la monnaie mise dans le tiroir) dans l'écran [Caisse](route:/cash).
- [ ] Faites une vente d'essai puis un retour, pour voir le ticket et le bon de retour.
- [ ] Clôturez la caisse le soir (Z) : une sauvegarde est faite automatiquement.

> Pour vous entraîner sans toucher à vos vraies données, ouvrez la [boutique de démonstration](help:demo).
