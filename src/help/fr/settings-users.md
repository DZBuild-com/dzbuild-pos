# Utilisateurs et rôles

## Utilisateurs

- Créez un utilisateur par personne : le journal des opérations dit alors qui a fait quoi.
- Chacun a son code PIN de 4 à 8 chiffres.
- Chacun a sa langue : DZBuild POS s'affiche dans la sienne quand il se connecte.

## Rôles

- Les rôles intégrés : Propriétaire, Gérant, Caissier et Magasinier.
- « Nouveau rôle » crée votre propre rôle : cochez « Ce que ce rôle peut faire ».

## Sécurité

- Cinq codes PIN erronés bloquent la connexion pendant 5 minutes.
- L'écran se verrouille tout seul après le temps choisi sans activité.
- Une action au-delà des droits d'un utilisateur demande l'accord d'un responsable, avec son code PIN.
