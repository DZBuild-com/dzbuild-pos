# Supprimer toutes les données

## Avant tout

- La loi demande de garder les ventes, les factures et le journal des opérations pendant 10 ans.
- Exportez-les d'abord : « Exporter mes données » dans [Réglages › Sauvegardes](route:/settings/backups) et, pour les factures, l'[archive fiscale](help:fiscal).

## La désinstallation garde les données

- Désinstaller DZBuild POS ne supprime jamais le dossier `%APPDATA%\dev.dzbuild.pos`.
- La case du programme de désinstallation n'efface que des fichiers d'affichage temporaires, jamais vos données.

## Supprimer vraiment

1. Fermez l'application.
2. Supprimez à la main le dossier `%APPDATA%\dev.dzbuild.pos` : dans l'Explorateur, tapez ce chemin dans la barre d'adresse.
3. Au démarrage suivant, l'assistant d'installation s'ouvre.
