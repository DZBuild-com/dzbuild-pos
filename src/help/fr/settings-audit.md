# Journal des opérations

## Ce qui est noté

Le journal des opérations note les connexions, les ventes, les annulations, les remises, les ouvertures du tiroir, les changements de réglages, les sauvegardes et les mises à jour.

## Vérifier le journal

« Vérifier le journal » prouve qu'aucune ligne n'a été modifiée ni supprimée : chaque ligne est scellée à la précédente, donc tout changement se voit.

## Historique d'une fiche

« Historique », sur la fiche d'un produit, montre qui a changé quoi, avec la valeur avant et après.
