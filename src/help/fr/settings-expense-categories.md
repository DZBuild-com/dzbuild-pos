# Catégories de dépenses

## Les catégories

- Chaque dépense enregistrée dans [Caisse](route:/cash), onglet « Dépenses », reçoit une de ces catégories.
- « Nouvelle catégorie » en ajoute une, avec son code, son nom et son ordre dans la liste.

## Le groupe dans la caisse

Le groupe décide sur quelle ligne du rapport Z apparaît une dépense payée avec l'argent du tiroir.

## Archiver

- « Archiver » retire une catégorie des nouvelles dépenses ; les dépenses déjà enregistrées la gardent.
- « Afficher les archivées » les montre de nouveau.
