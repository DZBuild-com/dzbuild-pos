# جولة في دقيقتين

ست شاشات يجب معرفتها. كل خطوة تستغرق عشرين ثانية.

## 1. البيع

تُفتح شاشة البيع لأمين الصندوق. امسح رمزًا شريطيًا أو اكتب اسمًا: يُضاف السطر. المبلغ الواجب دفعه في الشريط الأصفر. `F12` للقبض.

## 2. القبض

اختر نقدًا أو CIB أو الذهبية أو بريدي موب أو صكًا. يُحسب الباقي وحق الطابع تلقائيًا. تُطبع التذكرة ويُفتح الدرج.

## 3. الصندوق

في الصباح، افتح الصندوق بمبلغ الافتتاح. في المساء، عُدّ وأغلق (Z). يُطبع Z وتُحفظ نسخة احتياطية.

## 4. المنتجات والمخزون

في المنتجات، أنشئ سلعك أو استوردها برموزها الشريطية وأسعارها. ينقص المخزون مع كل بيع ويزيد مع كل استلام.

## 5. الإعدادات

المتجر، والمستخدمون وصلاحياتهم، والعتاد، والنسخ الاحتياطية، والتحديثات. كل تغيير مهم يُسجَّل في سجل العمليات.

## 6. المساعدة

`F1` يفتح صفحة مساعدة الشاشة التي أنت فيها، بالعربية أو الفرنسية أو الإنجليزية، دون إنترنت.

> تريد التجربة؟ [المتجر التجريبي](help:demo) يحتوي على منتجات ومبيعات للتدرّب.
