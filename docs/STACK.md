# DZBuild POS: stack and architecture

The background for these choices is in `docs/research/07-tech-stack.md` (framework comparison),
`05` (hardware) and `06` (DZBuild account link).

## Targets

- Windows 10 1809 or later and Windows 11, 64-bit and 32-bit. Windows 7 is not supported (current
  Tauri and Rust no longer target it).
- Low-end shop PCs: 4 GB of RAM, Celeron, hard disk, frequent power cuts.
- Works fully offline. The internet is used only for updates and the optional DZBuild link.
- Arabic (right to left), French and English for the interface and the printed documents. Each user
  picks a language; each customer or document can have its own print language.

## Layers

| Layer | Choice |
|---|---|
| Shell | Tauri 2 (Rust and WebView2): single instance, tray icon, customer display window |
| UI | React 19, TypeScript, Vite 8, Tailwind 4, shadcn/ui with RTL, TanStack Table and Virtual, TanStack Query, Zustand for the cart, react-hook-form and zod, i18next, `Intl` for amounts in DZD and dates |
| IPC | TypeScript bindings generated by tauri-specta. The UI has no SQL access |
| Database | SQLite via rusqlite (bundled) in WAL mode, `synchronous=FULL` on the writer, one writer thread and a reader pool, forward-only migrations with rusqlite_migration, UUIDv7 ids, append-only stock and cash ledgers, hash-chained audit journal |
| Several tills | The same program runs as standalone, main PC or till. The main PC serves HTTP and WebSocket with axum and announces itself over mDNS (`_dzpos._tcp`). Tills keep a local copy and an outbox with idempotency keys, so they keep selling when the main PC or the network is down |
| Printing | ESC/POS written in-house, sent through the Windows spooler (RAW), USB, TCP 9100 or COM. Arabic receipts are shaped with cosmic-text and printed as a 1-bit raster (`GS v 0`). Labels in TSPL or ZPL. A4 and A5 documents are HTML templates printed or saved as PDF by WebView2 |
| Peripherals | Keyboard-wedge and serial scanners (with AZERTY and Arabic layout handling), serial scales and EAN-13 weight barcodes, cash drawer, VFD pole display, customer screen on a second monitor |
| Import and export | calamine (xlsx, xls, ods), rust_xlsxwriter, csv with encoding_rs for Windows-1256 and Windows-1252 files; import wizard with column mapping, preview and error report |
| DZBuild link | OAuth 2.0 public client with PKCE, or a device code; tokens in the Windows Credential Manager |
| Licence | `crates/pos-license` checks Ed25519-signed per-PC licences offline. It is turned off in the free edition (`free = true` in `src-tauri/license.toml`); see `docs/release/licensing.md` |
| Updates | Tauri updater with a mandatory signature, stable and beta channels, installed only when every cash drawer is closed, database backup before a migration. The main PC passes verified updates to its tills |
| Installer | NSIS online setup (WebView2 bootstrapper) and offline setup with WebView2 included; firewall rules for the main PC role; installer in Arabic, French and English |
| Backups | Automatic rotating local backups, second copy, USB copies, guided restore, integrity check |
| Logs | tracing with daily log files kept 14 days, diagnostic ZIP, Windows Error Reporting dumps |
| Tests | cargo test with insta snapshots and proptest (money, tax, stock), Vitest with mocked commands, Playwright end-to-end tests on Edge, ESC/POS output snapshots |

## Repository layout

```
Cargo.toml          workspace
crates/pos-core     business logic, database, migrations, sync (no Tauri dependency)
crates/pos-docs     receipts, invoices, amounts in words, xlsx/csv import and export
crates/pos-hw       printers, Arabic raster, labels, scales, drawer, pole display
crates/pos-server   main PC role for several tills (axum, mDNS)
crates/pos-license  offline licence check (off in the free edition)
src-tauri/          desktop shell; commands are thin wrappers over pos-core
src/                React interface, strings in src/locales/{ar,fr,en}
```

## Known constraints

- WebView2 memory use on 4 GB PCs.
- Windows SmartScreen warnings until the setups are code-signed.

## Brand

- Name: **DZBuild POS**. Logo files are in `assets/brand/` (mark, vertical and horizontal, SVG and
  PNG). Regenerate them with `node assets/brand/gen-logo.mjs`.
- Colours: brand yellow `#FFC300`, primary amber `#F59E0B`, ink `#1C1917`, light background
  `#FBFAF7`. Fonts: Cairo (Arabic) and Inter (Latin), bundled with the app.
