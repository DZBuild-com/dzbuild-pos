# DZBuild POS brand assets

The DZBuild POS mark is the DZBuild mark (yellow circle, smiling shopping bag) with the bag's bottom edge turned into a torn receipt. The wordmark is "DZBuild" in brand yellow followed by a "POS" pill.

Every file here except `dzbuild-logo.png` and `fonts/` is generated by `gen-logo.mjs`. Do not edit the SVGs or PNGs by hand.

## Files

All SVGs are outlined (no `<text>`, no font needed) and have no background. All PNGs are RGBA with a transparent background.

| File | Size (px) | Use |
|---|---|---|
| `app-icon.png` | 1024 × 1024 | Source for `pnpm tauri icon assets/brand/app-icon.png` (ICO, Store and installer icons). The circle fills 88% of the canvas. Strokes are heavier than in the mark so the face still reads at 32 and 48 px. |
| `dzbuild-pos-mark.svg` | 512 × 512 | Mark only: favicon, tray, avatars, in-app places where the name is already shown. |
| `dzbuild-pos-mark.png` / `dzbuild-pos-mark@1024.png` | 512 / 1024 | Raster copies of the mark. |
| `dzbuild-pos-logo-horizontal.svg` / `.png` | 1138 × 320 | App header on light surfaces, docs, README, website, installer header image (NSIS header, 150 × 57 BMP, derived at release time). |
| `dzbuild-pos-logo-horizontal-on-dark.svg` / `.png` | 1138 × 320 | App header on dark surfaces (dark theme). |
| `dzbuild-pos-logo.svg` / `.png` | 1024 × 1024 | Vertical logo: splash screen, About dialog, installer welcome/sidebar image (NSIS sidebar, 164 × 314 BMP, derived at release time), printed material. |
| `dzbuild-pos-logo-on-dark.svg` / `.png` | 1024 × 1024 | Vertical logo on dark surfaces (dark splash, dark slides). |
| `dzbuild-logo.png` | 1563 × 1563 | Parent DZBuild logo, reference only. Not generated and not for POS use. |

In the React app, import the SVGs as assets and switch between the light and on-dark files with the theme. The logo is never mirrored in Arabic (RTL). Place it at the inline-start of the header like any other content.

## Colours

| Token | Hex | Where |
|---|---|---|
| Yellow | `#FFC300` | Circle, wordmark, smile, eyes, receipt dots; "POS" pill on dark surfaces |
| Ink | `#1C1917` | "POS" pill on light surfaces; "POS" text on dark surfaces; reference dark surface |
| White | `#FFFFFF` | Bag and handle; "POS" text on light surfaces |

The light files use an ink pill with white "POS" text. The on-dark files use a yellow pill with ink "POS" text, so the pill stays visible on `#1C1917` and similar backgrounds. The yellow wordmark is the same in both.

## Typography

- Font: **Inter ExtraBold** (Inter 4.1), `fonts/Inter-ExtraBold.ttf`. The parent DZBuild wordmark uses the same letterforms (x-height, notched `u`/`d`, tailed `l`), so the POS wordmark matches it.
- Shaping uses fontkit with the font's own GPOS kerning and the `cv05` feature (tailed `l`, like the parent wordmark).
- "DZBuild" tracking is −0.05 em, measured from the parent wordmark. One pair gets extra space: `l`+`d` gets +0.015 em so the tail of the `l` does not touch the `d`.
- "POS" cap height is 0.56 × the "DZBuild" cap height, with +0.01 em tracking. The text is centred in the pill.
- Pill proportions, as multiples of the "DZBuild" cap height: height 1.18, horizontal padding 0.36, gap after the wordmark 0.30. Corner radius is 0.27 × the pill height. The pill is centred on the cap band of the wordmark.

## Usage rules

- Keep at least the padding already built into each file. Do not crop tighter.
- Minimum sizes: horizontal logo 24 px tall, mark 16 px.
- Do not recolour, stretch, rotate, outline, or add effects to the logo, and do not mirror it for RTL.
- Do not retype the wordmark in a live font. Use the SVGs.
- On a dark background, use only the `-on-dark` files. The ink pill of the light files disappears on dark.

## Regenerate

```sh
pnpm install                     # once, installs fontkit + @resvg/resvg-js
node assets/brand/gen-logo.mjs   # works offline and from any directory
```

The output is deterministic: running the script twice gives byte-identical files. To change colours, font settings, pill proportions or layout padding, edit the token block at the top of `gen-logo.mjs`. Do not edit the generated files.
